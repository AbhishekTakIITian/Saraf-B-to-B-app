# Project Guidelines & Rules

## Icon Standards
- **FontAwesome SVGs**: From now onwards, all icons must use FontAwesome in raw SVG format (`<svg xmlns="http://www.w3.org/2000/svg" viewBox="..." aria-hidden="true"><path d="..."/></svg>`).
- Ensure SVGs are styled properly with `fill: currentColor` and explicit width/height (or parent flex/alignment styling) so they render crisp, visible, and inherit color appropriately across themes.
- Do not use emoji icons (e.g. 🙈, 👁️) or stroke-based placeholder shapes for interactive elements like password toggle buttons.
- Always reference and adhere to these guidelines for every change in the project.
